Subscribe to the calendar

One link, added once. New incidents you publish later show up automatically — no need to resubscribe.

calendar.ics Copied ✓
Paste that link into your calendar app's "Subscribe from URL" (sometimes called "Add calendar from Internet" or "From URL"). Not sure where that is? Open the instructions for your app below.
New incidents get added to this same feed regularly. If you used "Subscribe" above, your calendar app checks for updates automatically — but the timing is controlled by your calendar app, not by us, and can take anywhere from a few hours to a day or two. If you used "Import" instead (see below), new incidents will never appear automatically — you'll need to re-import periodically.
Google Calendar
  1. On the left sidebar, next to "Other calendars," click +
  2. Choose "From URL"
  3. Paste the link, click Add calendar
Reminders aren't on by default for subscribed calendars — after adding it, go to Settings → this calendar → Notifications, and turn on "Event notifications."
Apple Calendar
  1. Open the Calendar app → menu File → New Calendar Subscription...
  2. Paste the link, click Subscribe
  3. Set auto-refresh frequency (daily is fine) and click OK
Outlook
  1. Go to Calendar view → File → Account Settings → Account Settings...
  2. Open the Internet Calendars tab → click New...
  3. Paste the link, click Add
Work computer blocks subscriptions? Ask IT to allow it

Many companies block calendar subscriptions from external URLs by default — this is a policy setting an admin can change in minutes. Before falling back to Import below, try forwarding this to your IT or helpdesk team:

Hi — could you allow-list the following calendar subscription URL so I can subscribe to it in my work calendar? It's a read-only feed with no attachments or executable content, just calendar events.

URL: calendar.ics

For Google Workspace, this is usually under Apps → Google Workspace → Calendar → Sharing settings. For Microsoft 365, it's under external sharing policies for internet calendar subscriptions. Thanks!

This is worth trying first — it fixes the problem permanently instead of needing a manual workaround every month.

Can't subscribe? (e.g. work computer blocks it) — Import as a last resort

Only use this if "Subscribe from URL" genuinely doesn't work for you — for example, your workplace's IT policy blocks calendar subscriptions from external URLs. If you can subscribe normally, do that instead; it stays current automatically and this doesn't.

  1. Click Download .ics file below
  2. In your calendar app, look for Import (Google: Settings → Import & Export. Outlook: File → Open & Export → Import/Export)
  3. Select the downloaded file

Important: this adds a one-time snapshot. New incidents added later will NOT appear — you'd need to re-download and re-import this file periodically to stay current. A true "Subscribe from URL" (above) updates automatically; this does not.

If you're relying on Import, we'd suggest re-importing every 1–3 months. Check the "last updated" date in the footer below before you bother re-importing — if it hasn't changed since your last import, there's nothing new yet.
